# AGENTS.md

## Agent skills

### Issue tracker

Issues live as GitHub issues on `designnotdrum/process-pack`, operated via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical triage roles, each label string equal to its name. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `CONTEXT.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.

### Docs voice

Write and update docs by `docs/agents/docs-voice.md`. The `docs-refresh` workflow applies it on every pull request.
