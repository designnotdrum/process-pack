# F22 — Settling three knobs

You are the orchestrator. In a polish playground for a card component, the designer has settled three knobs and hit commit:

1. **Gap = 96**, where the system's spacing token would give 100. They say: "just here — the thing next to it is heavy, so 100 reads as too much."
2. **Card density = cozy**, changed from the system default of "roomy". They say: "roomy was always too airy for these cards; this should be the default."
3. **Focus-ring color** set to a new value that does not exist anywhere in the token system yet. They say: "we don't have a focus token at all — we should."

For each settled value, what do you do?
